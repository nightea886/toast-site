# 🍞 吐司大王 · 群友限定小站

主播「吐司大王」的个人官网：**相册 / 表情包 / 歌曲 / 歌单** 四大板块，暗色「深夜烘焙坊」风格，
电脑与手机端自适应。**纯静态站点，零服务器成本，托管在 GitHub Pages**。

---

## 一、它能做什么

| 板块 | 功能 |
| --- | --- |
| 相册 | 分类筛选（全部 / cosplay / 日常）、上传可选分类、网格展示、大图查看、原图保存；管理员可删任意、成员可删自己上传的 |
| 表情包 | 分类筛选（全部 / 图片 / GIF）、静图 + 动图 GIF 上传/展示/保存，GIF 自动打角标；删除权限同上 |
| 歌曲 | 模糊搜索（歌名 / 歌手，支持子序列匹配）、音频上传、底部播放器在线播放、下载；删除权限同上 |
| 歌单 | 按歌手分组；**仅管理员可编辑**，群友可查看；一键生成 **9:16 高清歌单长图**（2160 宽、2 倍像素，版式同示例图） |

另有：进入密码门禁（成员 / 管理员两种身份）、拖拽上传、极简设置面板（换密码工具 / 退出门禁）。

## 二、部署到 GitHub Pages（无需域名和服务器）

1. 在 GitHub 新建仓库，例如 `toast-site`（免费账号做 Pages 需为 **public** 仓库）。
2. 把本文件夹全部内容推送上去：
   ```bash
   git init && git add -A && git commit -m "init: 吐司大王小站"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/toast-site.git
   git push -u origin main
   ```
3. 仓库 → **Settings → Pages** → Source 选 **Deploy from a branch** → 分支 `main`、目录 `/ (root)` → Save。
4. 约 1 分钟后访问 `https://<你的用户名>.github.io/toast-site/` 即可。手机电脑同址访问。

> 媒体文件（图片/音频）会提交进仓库 `media/` 目录，由 Pages 直接分发，**不需要任何服务器**。
> 仓库建议控制在 1GB 内；以后媒体太多可迁移到对象存储，站点代码不用大改。

## 三、进入密码、管理员与上传（必读）

1. **进入密码**（成员身份）：打开网站先输入密码才能进入，输对一次该浏览器**永久豁免**。
   代码里只存密码的 **SHA-256 哈希**（`assets/js/config.js` 的 `gateSha256`），明文密码只出现在微信群公告里。
   - 初始成员密码：`148971`（**部署后请尽快更换**，方法见下）。
   - 豁免存在各人自己的浏览器里；换浏览器 / 换设备需重新输入。
   - **换密码时**：替换哈希并推送后，所有成员在所有设备上的豁免同时失效、需重输新密码，无需其它操作。
2. **管理员密码**（`adminSha256`）：用它进入即**管理员**，可删除任意相册 / 表情包 / 歌曲；
   成员密码进入则只能删除**自己上传的内容**（按该浏览器匿名 ID 识别）。
3. **上传零配置**：上传凭证以 **AES-GCM 密文**存在 `assets/js/config.js`（密钥 = 门禁密码的哈希），
   任何设备输密码进门时在浏览器内自动解密出凭证，即可上传 / 删除 / 保存歌单；
   密文不是 token 明文，不会触发 GitHub 吊销。换密码时站内「更换密码」会用新密码重加密密文。
   群公告种子链接（`#tk=`）保留为兜底渠道。

**主播操作清单：**

- 发群公告（模板）：

  > 进入链接（点一次自动带上传凭证）：https://nightea886.github.io/toast-site/#tk=ghp_xxx
  > 进入密码：`xxxxxx`（输一次永久进）。
  > 链接与密码勿外传！

  管理员密码单独私发给管理员，不进群公告。
- **换进入密码**：网站⚙设置 →「换进入密码」输入新密码 → 复制生成的哈希 → 替换
  `assets/js/config.js` 中 `gateSha256`（或 `adminSha256`）一行 → 提交推送 → 群里发新明文密码。
  推送生效（约 1 分钟）后，所有人已保存的进入状态自动失效。
- **换上传凭证**（泄露或到期时）：GitHub 上 revoke 旧 token → 新签一枚 classic token（只勾 **public_repo**）→
  拼新的种子链接发群；成员再点一次新链接即可（本机旧凭证被自动覆盖）。

## 四、日常使用

- **上传**：各板块「＋ 上传」按钮或直接把文件拖进虚线框；提交后 GitHub Pages 约 1 分钟全站生效
  （上传者本人立即能看到本地预览）。
- **删除**：卡片 / 歌曲行悬停出现 🗑。管理员可删任意内容；成员只在自己上传的内容上看到删除按钮。
  删除同样约 1 分钟全站生效。
- **歌单长图保存**：生成后弹出预览层；电脑自动下载，手机微信内请**长按预览图中的图片**保存到相册
  （微信浏览器屏蔽程序化下载，长按是官方保存方式）。
- **歌单**：「✎ 管理歌单」（仅管理员）里改标题/副标题/页脚、增删歌手分组、每行一首歌编辑曲目，「保存歌单」提交；
  「🖼 生成 9:16 歌单长图」输出暖色系高清长图（2160 宽、2 倍像素，版式配色同示例图），
  生成后弹预览层：电脑自动下载，微信内长按图片保存。
- **没有凭证的成员**：可正常浏览（过门禁后），点上传/保存歌单时会引导导出 `manifest.json`，
  交给有凭证的人提交即可。

## 六、目录结构

```

assets/css/main.css   暗色主题与响应式
assets/js/config.js   门禁/管理员哈希、仓库地址、内置上传凭证、兜底数据
assets/js/gh.js       GitHub API 提交（零服务器上传）
assets/js/store.js    状态与持久化
assets/js/playlist.js 歌单预览 + 9:16 暖色高清长图（纯 canvas）
assets/js/app.js      主控制器
data/manifest.json    全部内容的清单（上传/编辑会自动更新它）
media/                图片与音频（albums/ stickers/ songs/）
```
